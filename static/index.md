# Inua firmware

This page hosts the firmware releases of Inua, the gesture cube for Home Assistant made by
[HELUX LABS](https://heluxlabs.ar).

Inua units check this site for updates and install them over the air from Home Assistant. You do
not need to download anything from here.

- Source code and documentation: [github.com/HeluxLab/inua](https://github.com/HeluxLab/inua)
- Update manifest: [firmware/inua.manifest.json](firmware/inua.manifest.json)
